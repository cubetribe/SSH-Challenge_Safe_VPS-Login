# Security Policy

## Supported versions

There is no stable release yet. The repository is currently in bootstrap stage.

## Reporting a vulnerability

Please report security issues privately by email:

Dennis Westermann
<hey@dennis-westermann.de>

Do not open a public issue for suspected authentication bypasses, replay
vulnerabilities, signer validation bugs, leaked secrets, or deployment
weaknesses.

Helpful reports include:

- affected commit or version
- reproduction steps
- expected and actual behavior
- impact assessment
- whether any secret, key, or production host was exposed

Please do not include private keys, live production signer files, bearer tokens,
or real user data in the report.
